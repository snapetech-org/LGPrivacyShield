# Changelog

## 0.4.0 (unreleased)

- Added source-scoped settings profiles for B, C, and G OLED families across
  supported webOS versions, with model/software overlays for published reports.
- Added firmware package identity data and a key-registry import tool. Firmware
  package metadata does not enable controls.
- Added read-only status for additional published settings and clearer
  compatibility evidence limits.
- Added a source-backed accepted/declined effect map for LG agreements, plus
  visible unmapped status for additional model or region-specific agreements.
- Expanded headless Chromium, Python, firmware-catalog, and package checks.
- Added the About screen, AGPL-3.0-only licensing, third-party notices, and Ko-fi
  links.
- Use one QR code to open GitHub's compatibility form with the report pre-filled.
  The issue is created only when the form is submitted.
- Added a page-by-page user guide with headless screenshots and a documentation
  index.

## 0.1.12

- Added QR codes for transferring a sanitized compatibility report and opening
  its issue form.

Earlier release history is available in the
[GitHub release list](https://github.com/snapetech-org/PrivacyShield/releases).
