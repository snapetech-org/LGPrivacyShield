# Security policy

Use the latest source version for security fixes. The current unreleased source
version is listed in `package.json` and `webos-app/appinfo.json`.

For a vulnerability that could expose TV data, change settings without
authorization, or compromise a TV or Homebrew service, report it privately
through GitHub's repository security advisory feature if available. Do not post
exploit details, credentials, TV identifiers, or unredacted reports in a public
issue.

Include the affected version, model/software scope if known, reproduction
steps, and the impact. Do not run tests against TVs or networks you do not own
or have permission to assess.
