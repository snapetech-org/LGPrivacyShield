# Homebrew catalog entry draft

The source repository is
[snapetech-org/PrivacyShield](https://github.com/snapetech-org/PrivacyShield).

The catalog entry is in [org.privacyshield.webos.yml](org.privacyshield.webos.yml).
It points to the latest release manifest and uses the supported Ko-fi funding
field. Its Markdown description also includes a clickable support link for the
Homebrew Channel details page. A published release containing the matching IPK
and generated manifest must exist before submission. This entry is a local
draft; do not submit it to
`webosbrew/apps-repo/packages/` without project maintainer sign-off.
