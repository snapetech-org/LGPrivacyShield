# Homebrew catalog entry

The application source and release assets are published at
[snapetech-org/PrivacyShield](https://github.com/snapetech-org/PrivacyShield).
The v0.1.4 package includes the installable IPK and its matching manifest.

The catalog entry is in [org.privacyshield.webos.yml](org.privacyshield.webos.yml).
It uses the latest release manifest, so future releases do not require a catalog
URL change. Submit that file to `webosbrew/apps-repo/packages/`.
