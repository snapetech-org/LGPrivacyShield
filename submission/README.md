# Homebrew catalog preparation

[snapetech-org/PrivacyShield](https://github.com/snapetech-org/PrivacyShield).

[org.privacyshield.webos.yml](org.privacyshield.webos.yml). It includes the
catalog's Ko-fi funding field and a clickable support link. The manifest URL

[webosbrew/apps-repo#296](https://github.com/webosbrew/apps-repo/pull/296).

merge a catalog update until the project owner signs off. See
[release preparation](../RELEASE.md) and the
